# 模拟激励广告测试

当前没有接入 TikTok 广告网络，不需要 Placement ID，也不会产生广告收益。

1. 在 Cocos 预览或一键真机调试中运行游戏，失败后点击右侧 Continue。
2. 在 TEST AD / 测试广告面板选择：
   - COMPLETE / 看完：保留分数，安全位置复活，3 秒倒计时后恢复游戏。
   - CANCEL / 取消：回到失败界面，保留本轮复活机会。
   - FAIL / 失败：显示失败提示，保留本轮复活机会，可以重新尝试。
3. 看完复活后再次死亡，只能重玩；重玩后重新获得一次复活机会。
4. 检查广告面板期间无法穿透点击重玩；音乐在面板打开时暂停，关闭后恢复原先播放状态。

GameOverUI 组件的 Enable Mock Ads 是开发开关，目前默认开启，以便手机使用压缩构建测试。
关闭后，因为真实广告尚未配置，请求会失败并保留机会，绝不会自动发放复活。
发布前必须关闭该开关，并接入、验证真实广告提供方。当前构建仅用于模拟测试。

接入真实广告时替换 requestReviveReward 的提供方，保留 completed / cancelled / failed 结果边界。
仅完整观看回调可以返回 completed。不得以展示成功、无配置或请求失败作为奖励条件。
运行 node tests/score-reset.cjs 检查三种结果、重复点击、场景过期回调和单轮复活限制。
